## 1. 執行摘要：為何 V0.9 → V1.0 是新加坡 Buildathon 的分數躍遷

V0.9 在 Open House 評審眼中屬於 **飽和象限**：跨鏈橋 + APY 疊加 + 可升級金庫。痛點可被任意 Yearn/Beefy/跨鏈聚合器複述；變現依賴績效費與 TVL 幻想；Sponsor 協同停留在「我們也接了橋」；合約安全是標準 OZ proxy；架構是分鐘級 Cron；創新無法回答「為什麼必須是 Arbitrum / 為什麼必須是現在」。對 **70k Overall / 15k Promising / Sponsor 專項** 而言，這條路徑的期望值是 **中位淘汰或安慰獎敘事**。

V1.0 把產品身份重寫為 **AI Agent 在廣播前就被熔斷的安全 Citadel**：prompt injection、MEV 三明治、清算級有毒流，在 Bundler / mempool **之前**被 `checkSoilResistance()`（p50 ~106µs · Wasm 熱路徑）與 R01–R20 矩陣攔截（0-Gas）。變現錨在 **GMX v2 `uiFeeReceiver` +10 bps**（v1.0 已注入 payload）與 **V2.0 CaaS 10 bps 協議授權費**（路線圖，不得口播為已開徵）。獲客錨在 **ZeroDev EIP-7702 EOA→Agent SA** 與 `@slivervine/citadel-sdk` 預簽署鉤子。合約錨在 **無代理、consume-once `SliverVineGate`** + Halmos `check_*` 契約。賽制錨在 **Arbitrum One 主戰場 + Robinhood 46630/4663 出站護航資格**。證明錨在 **Proposal Baseline: 175 test files | 773 PASS (Current Branch Live: 176 test files | 775 PASS Clean)** 與 `GET /api/grant-audit`。

**分數機制（評審主席視角）：**

| 機制 | V0.9 後果 | V1.0 後果 |
|------|-----------|-----------|
| 痛點可複述性 | 與 50 個 vault 撞車 → 維度 (1)(7) 封頂 5 | Agent 小腦 + 0-Gas 攔截 → 維度 (1)(7)(14) 進入 8 分帶 |
| Sponsor 可截圖證據 | 「我們接了橋」無法拿 GMX/Robinhood 專項 | 10 bps payload + 單向 AML + Pendle expiry guard + Dune 規格 |
| 賽制雙保留獎 | 部署足跡不清 → 維度 (11) 失格風險 | Sepolia Gate 可驗 + 46630 出站測試 → 雙獎可同時競標 |
| 誠實範圍 | APY 數字理論化 → 維度 (12)(10) 被打假 | Sepolia / dry-run / 模擬名義保護寫死 → Grant 評審加誠實分 |
| 技術護城河 | Cron + RPC → 維度 (6)(8) 被 HFT 評審歸零 | Wasm Edge + `SystemState` 單向流 + 簽名通道切斷 |

**結論：** V0.9 是「可以活著打完黑客松」的產品；V1.0 是「可以進入 Promising Track 決賽圈、並同時競標 GMX / Robinhood / Arbitrum 保留獎」的產品。Δ +2.5 分在 10 分制下足以改變獎金路徑，前提是 **不把 Stylus 上鏈、Dune 合成標籤、蒙地卡羅 $9.88M、CaaS 10 bps 說成已實現主網現金流**。

## 3. 十四維度深潛（技術量子躍遷 × 獎金分數影響）

### (1) 痛點（Pain Point & Identity）

**V0.9：** 痛點被表述為「APY 不夠高 / 跨鏈收益碎片化」。評審聽過一百次。身份是 Generic Yield Vault。任何對手用更高 APY 投影即可壓過。

**V1.0：** 痛點重寫為 **無人值守 AI Agent 在 Arbitrum 上的預廣播死亡窗口**：prompt injection 誘使簽署有毒 UserOp、MEV 三明治在 mempool 可見之後才「風控」、清算級深度崩潰時 LP / Agent 仍廣播。SliverVine Citadel 的回答是 **0-Gas 預廣播攔截**——意圖未進 Bundler 即被熔斷。身份句鎖定：*Sub-ms 0-Gas Pre-Broadcast Safety Citadel & Risk Navigator for AI Agents on Arbitrum*。

**分數影響：** 維度 (1) 從 5.8 → 8.4。主席評審 Jessica Alba：這是 Promising Track 的入場券；沒有這句，Overall 會把項目丟進「又一個 GMX 包裝」。

---

### (2) 變現（Monetization & Business Model）

**V0.9：** 投機性績效費（超越 hurdle 抽成）。無鏈上 builder 證據，評審視為「有 TVL 才有故事」。

**V1.0：** 雙軌、必須口播分層——**(a) 已交付：** GMX v2 每筆合格 payload `uiFeeReceiver` **+10 bps**（`GMX_UI_FEE_BPS` · `gmx-v2-order-payload.ts`）；**(b) 路線圖：** V2.0 CaaS `@slivervine/citadel-sdk` **10 bps 協議授權費**（預執行檢查，**不得**與 GMX UI fee 混為同一筆現金流）。績效費 / Aave 基準仍標 *(Hurdle-rate probe only — not a yield-stacking product track)*。

**分數影響：** 維度 (2) 5.8 → 7.8。黃志偉 / David Chen：可截圖的 10 bps 比白皮書績效費值錢。扣分點：主網 `claimUiFees` 未跑、CaaS 費未開徵。

### (3) 獲客（Go-To-Market & Onboarding）

**V0.9：** 用 APY 廣告釣零售 LP。漏斗熟悉，但 Buildathon 評審不發「零售增長」獎。

**V1.0：** ZeroDev Kernel v3 + **EIP-7702 EOA→Agent SA**（V1.5 路線圖須標 ⏳）+ `@slivervine/citadel-sdk` 的 `guardAgentUserOp` / `verifyAgentIntent`。ElizaOS / LangChain 為 **鉤子表面**，倉庫內無獨立 `eliza-plugin` 套件——Chloe Dubois 已扣分。

**分數影響：** 維度 (3) 僅 +0.6（6.2 → 6.8）。這是全場最小躍遷：V0.9 的零售敘事至少「聽得懂」；V1.0 的 Agent 獲客工程正確但 **缺少可 npm 安裝的框架適配器與主網 UserOp 成交**。Pitch 應誠實：「基礎設施鉤子已交付，分發適配器是 V1.5/V2.0。」

### (5) 安全/合約（Contract Security & Formal Invariants）

**V0.9：** 標準可升級 proxy。機構評審視為「治理即後門」。halt/unhalt 對稱。資金路徑與策略合約耦合。

**分數影響：** 維度 (5) 5.6 → 8.3。林浩然 / Alex Rivera 給 Gate 9 分帶。A5 類扣分：僅 Sepolia；Edge `sever` 與鏈上 `STATUS_SHUTDOWN` 非同一原子事務。

**分數影響：** 維度 (6) 5.5 → 8.1。陳詩涵：Stylus coprocessor 代碼 5/5、**上鏈 pending** 必須字幕標明，否則從 8.5 打到 5。
