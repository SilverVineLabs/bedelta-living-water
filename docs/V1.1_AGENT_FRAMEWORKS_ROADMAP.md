## 0. 執行摘要

Citadel 定位為 **通用 DevSecOps 預執行安全層（Pre-Consensus Intent Firewall）**，在 AI Agent 框架（ElizaOS、Wayfinder、LangChain AgentKit 等）與鏈上簽名／Bundler 廣播之間插入 **0-Gas Fail-Closed** 熔斷。整合方 **不需修改 Citadel 核心程式碼**；僅需：

1. **內嵌 SDK** — `@slivervine/citadel-sdk` 的 `withCitadelShield()` / `verifyAgentIntent()`
2. **REST Edge API** — `POST /api/hedge/evaluate`（遠端 soil fuse + R20 通道狀態）
3. **Session Key 授權平面** — HL `approveAgent` + ERC-7579 clip 約束（Pillar 1 Opt-In）

V1.1 里程碑目標：將 v1.0 **Reference Harness** 升級為可發布的 npm Plugin 套件與 Wayfinder 正式路由，支援 DEX Grant 後的設計夥伴 onboarding。

#### 1.1.1 `agent-interceptor-demo.ts` 生命週期

```text
AGENT_INTENT_EMITTED
    │
    ▼
checkSoilResistance(soil)          ← Pillar 3 Wasm / TS hot-path (p50 ~106µs)
    │ FAIL → SIGNING_CHANNEL_SEVERED → USEROP_BLOCKED (0-Gas)
    ▼ PASS
assertCitadelRiskGate(soil)        ← ZeroDev AA gate · sequencerSafe
    │ FAIL → SIGNING_CHANNEL_SEVERED
    ▼ PASS
SIGNING_CHANNEL_OPEN → USEROP_DISPATCHED (ZeroDev Bundler → EntryPoint v0.7)
```

**關鍵設計：** Agent 框架僅需將 `SoilResistanceInput`（symbol、hlSpot、hlPerp、dydxPerp、depthUsd）注入 hook；Citadel 負責熔斷，框架負責 intent 編排。

### 1.2 Session Key 授權平面

| 模組 | 路徑 | 功能 |
|------|------|------|

**AllowedToSign 方程式（SDK SSOT）：**

```text
AllowedToSign = Injection ∧ Digest ∧ Soil ∧ Session ∧ Gas ∧ Attestation ∧ Armor ∧ Wasm
```

Agent 框架透過 **scoped Session Key**（maxOrderClipUsd、expiresAtMs）綁定執行範圍；Citadel 在簽名離開 Edge 前強制 clip 與 soil fuse。

### 1.3 API Gateway 入口（Soil Resistance 熔斷）

> **注意：** 實際 hot-path 位於 `src/services/risk-control-lib/soil-resistance.ts` 與 `src/core/risk-engine-lib/risk-engine-gateway.ts`（非 `src/risk-control/soil-resistance.ts`）。

| 入口 | 路徑 | 整合方式 |
|------|------|----------|
| **Soil Fuse 核心** | `src/services/risk-control-lib/soil-resistance.ts` | `checkSoilResistance()` — 跨場滑點、深度、sequencer、gas guard |
| **Gateway 規則引擎** | `src/core/risk-engine-lib/risk-engine-gateway.ts` | `evaluateGatewayRules()` — soil + vineWrapProtection fail-closed |
| **REST Hedge Evaluate** | `src/api/index.ts` → `POST /api/hedge/evaluate` | 遠端 Agent（Python / 無 Node SDK 環境）soil + R20 狀態查詢 |
| **Grant Audit 遙測** | `GET /api/grant-audit` | PEV / soil trip 遙測 · Dune 索引 SSOT |

#### REST 契約摘要（LangChain Python / CrewAI 使用）

```http
POST {CITADEL_API_URL}/api/hedge/evaluate
Content-Type: application/json

{
  "marketPrice": 0.05,
  "thresholdProb": 0.08,
  "soil": {
    "symbol": "ETH",
    "hlSpot": 3500,
    "hlPerp": 3500,
    "dydxPerp": 3500,
    "depthUsd": 200000
  }
}
```

| HTTP | code | 意義 |
|------|------|------|
| 200 | `success: true` | Soil PASS · hedge channel active |
| 422 | `SOIL_RESISTANCE_TRIP` | Fail-Closed · 0-Gas 預廣播拒絕 |
| 403 | `R20_LOCKED` | Signing channel severed · 物理硬鎖 |

## 2. 標準 AI Agent Framework 整合模式

### 2.1 整合拓撲（零核心修改）

```text
┌─────────────────────────────────────────────────────────────┐
│  AI Agent Framework (ElizaOS / Wayfinder / LangChain)       │
│  ├─ Plugin / Action / Tool / Route Handler                  │
│  └─ 僅呼叫 SDK 或 REST — 不 import Citadel 核心 Worker 邏輯   │
└──────────────────────────┬──────────────────────────────────┘
                           │
          ┌────────────────┼────────────────┐
          ▼                ▼                ▼
   withCitadelShield   verifyAgentIntent   POST /api/hedge/evaluate
   (decorator.ts)      (agent-intent.ts)   (api/index.ts)
          │                │                │
          └────────────────┼────────────────┘
                           ▼
              checkSoilResistance()  ← 外掛層唯讀呼叫
                           │
              FAIL → 0-Gas · signingChannelOpen: false
              PASS → Agent 繼續 EIP-712 / Bundler dispatch
```

**設計原則：** Citadel 不解讀自然語言 prompt；僅對 **結構化 intent payload**（soil 向量、Session Key clip、intent digest）執行 bytecode 級硬斷言。

### 2.2 ElizaOS — `@elizaos/plugin-citadel-guard` 規格

| 項目 | 規格 |
|------|------|
| **套件名稱** | `@elizaos/plugin-citadel-guard` |
| **授權** | Apache-2.0 |
| **依賴** | `@slivervine/citadel-sdk`（peer） |
| **Plugin 入口** | `citadelShieldPlugin` — 註冊 `actions: [citadelSoilGuardAction]` |
| **Action 名稱** | `CITADEL_SOIL_GUARD`（similes: `SOIL_CHECK`, `PRE_BROADCAST_GUARD`, `CITADEL_SHIELD`） |
| **Handler 簽名** | `(runtime: IAgentRuntime, message, state, options?) → [Content, didRespond]` |
| **核心包裝** | `withCitadelShield(executionFn)` — soil fuse + 60s `MANDATORY_COOLDOWN_ACTIVE` |
| **Reference SSOT** | `examples/adapters/elizaos-action-adapter.ts` |

#### Plugin 安裝（V1.1 目標 DX）

```typescript
// eliza.config.ts
import { citadelShieldPlugin } from "@elizaos/plugin-citadel-guard";

export default {
  plugins: [citadelShieldPlugin],
  settings: {
    CITADEL_API_URL: "https://bedeltawater.slivervine.xyz", // 可選 REST fallback
    CITADEL_AGENT_ID: "my-agent-0xbeef",
  },
};
```

#### Action Handler 整合點

1. Agent 產生 trade intent → 呼叫 `CITADEL_SOIL_GUARD` action
2. Action 將 `SoilResistanceInput` + `agentId` 注入 `withCitadelShield`
3. Soil PASS → 返回 `[{ text: "SOIL_PASS", action: "CITADEL_SOIL_GUARD" }, true]`
4. Soil TRIP → Fail-Closed + 啟動 60s cooldown（防止 LLM retry token burn）

**CLI 驗證：** `pnpm tsx examples/adapters/elizaos-action-adapter.ts [--trip]`

### 2.3 Wayfinder — Arbitrum Native Agent 路由規格

| 項目 | 規格 |
|------|------|
| **Hook 名稱** | `wayfinder_citadel_shield` |
| **整合層** | Wayfinder Agent Engine on-chain intent dispatch 前 |
| **雙層驗證** | `checkSoilResistance()` 探針 + `verifyAgentIntent()` 八維方程式 |
| **Session Key** | `sessionKey: { agentAddress, maxOrderClipUsd, expiresAtMs, approvedAtMs }` |

```typescript
// wayfinder.routes.ts
import { wayfinderCitadelShieldHook } from "@slivervine/citadel-sdk/wayfinder";

export const citadelPreDispatchRoutes = [
  {
    path: "/agent/intent/pre-dispatch",
    middleware: [wayfinderCitadelShieldHook.execute],
    chainId: 42161,
  },

```

**回傳契約：**

```typescript
interface WayfinderAgentResult {
  success: boolean;
  status: "ALLOW" | "FAIL_CLOSED" | "MANDATORY_COOLDOWN_ACTIVE";
  allowedToSign?: boolean;

  reasons?: string[];
}
```

### 2.4 LangChain AgentKit 整合模式

| 模式 | 適用場景 | 入口 |

## 3. DevSecOps 安全層定位

### 3.1 Citadel 作為通用安全層的三個平面

| 平面 | 機制 | Agent 框架所需改動 |
|------|------|-------------------|
| **Pillar 3 Shield（必備）** | `checkSoilResistance()` sub-ms soil fuse | SDK decorator 或 REST 一行程式 |
| **Pillar 1 Gatehouse（Opt-In）** | ZeroDev Kernel v3 Session Key · Paymaster | `verifyAgentIntent()` session 審計 |
| **Pillar 2 Ingress（可選）** | Robinhood escort · bridge AML | `assertUnidirectionalBridge()` |

### 3.2 Fail-Closed 保證

| 事件 | Agent 可見行為 | Gas 成本 |
|------|---------------|----------|
| Soil TRIP | `signingChannelOpen: false` · throw `RiskLimitExceeded` | **0-Gas** |
| R20 LOCK | HTTP 403 `R20_LOCKED` | **0-Gas** |
| Cooldown Active | `MANDATORY_COOLDOWN_ACTIVE` · 禁止 LLM retry | **0-Gas** |
| Sequencer UNSAFE | `assertCitadelRiskGate` sequencerSafe=false | **0-Gas** |

### 3.3 與競品框架差異（V1.0 Baseline）

| 維度 | Citadel V1.1 | Wayfinder | Virtuals | ElizaOS | ZeroDev AA |
|------|-------------|-----------|----------|---------|------------|
| 預廣播熔斷 | ✅ p50 ~106µs | ❌ 無 native soil | ❌ 無 | ❌ 無 | ⚠️ Bundler 後驗 |
| LLM Back-off | ✅ 60s per agentId | ❌ | ❌ | ❌ | ❌ |
| Session Key clip | ✅ R06/R07 | ⚠️ 自建 | ⚠️ 自建 | ⚠️ 自建 | ✅ ERC-7579 |
| 0-Gas Fail-Closed | ✅ | ❌ | ❌ | ❌ | ⚠️ 部分 |

### 4.4 風險與誠實限制（V1.1 聲明）

1. **非官方合作背書** — Reference Harness 不代表 Virtuals / ElizaOS / Wayfinder 官方認證；V1.1 目標為模組化 Plugin 規格與設計夥伴 PoV。
2. **費用路由 V2.0** — V1.1 不啟用 multi-platform agent fee routing；GMX +10 bps `uiFeeReceiver` 仍為唯一 v1.0 費用平面。
3. **EIP-7702** — EOA → Agent Smart Account 升級屬 **V1.5**；V1.1 僅文件化接口，不實作。
4. **核心零修改** — 所有 V1.1 交付物位於 `examples/`、`packages/`、`docs/`；`src/` 測試套件維持 803 PASS。
