SliverVine Protocol (BeDelta-Living-Water) is a pre-execution risk gateway and dynamic rebalancer for GMX v2 GM Pools on Arbitrum One. Built for delta-neutral vaults and automated hedging agents, it mitigates the critical vulnerability window where stale-oracle execution and adverse fills occur during RPC congestion or sequencer degradation — failure modes that conventional fail-open stacks pass straight to the order router.

BeDelta is fail-closed by construction. Pre-dispatch off-chain gates enforce hard probability bounds: blocking payload generation when Chainlink oracle lag exceeds 30,000 ms, estimated GMX price impact crosses 50 bps, or the Arbitrum Sequencer Uptime Feed exits its 600 s grace window. On-chain, execution outcome is bounded by non-zero minOutputAmount and explicit acceptablePrice ceilings. Deterministic verification: a 255-case spec-asserted matrix (scripts/chaos-blackswan-stress.ts) and a 65,535-iteration property fuzzer confirm 100% fail-closed boundary enforcement with 0 isolate crashes across toxic vectors.
