SliverVine Protocol (BeDelta-Living-Water) is a zero-trust pre-execution risk gateway and dynamic rebalancer for GMX v2 GM Pools on Arbitrum One. Built for delta-neutral vaults and automated hedging agents, it seals the critical vulnerability window where stale-oracle execution and adverse fills occur during RPC congestion or sequencer degradation — failure modes that conventional fail-open stacks pass straight to the order router.

BeDelta is fail-closed by construction. Pre-dispatch gates enforce hard bounds: blocking execution when Chainlink oracle lag exceeds 30,000 ms, estimated GMX price impact crosses 50 bps, or the Arbitrum Sequencer Uptime Feed exits its 600 s grace window. These off-chain gates constrain execution probability, while on-chain acceptablePrice slippage bounds restrict execution outcome. Verification is deterministic: a 255-case spec-asserted matrix (scripts/chaos-blackswan-stress.ts) and a 65,535-iteration fuzzer confirm 100% fail-closed boundary enforcement with 0 isolate crashes across all toxic vectors.

v0.8 is live and verifiable: 680 Vitest tests pass clean (125 test files, grant-ui-ssot), with real-time JSON telemetry at /api/grant-audit and a settled cross-venue hedge (0.2223 ETH short, OID 513344575969). Unsigned GMX payloads configure a treasury uiFeeReceiver (0xc9Bd...546f, Arbitrum block 494033232), accruing 5 bps on routed volume without altering GMX base fees. V1.0 proposes a decomposed 10 bps schedule — 5 bps base plus a gasless loss-protection premium capped at 0.5% annual AUM drag.

Fees accrue strictly on executions clearing every gate; a blocked trade earns zero revenue. Because gate thresholds are immutable compile-time constants rather than operator parameters, neither over-blocking nor loosening gates generates revenue.
